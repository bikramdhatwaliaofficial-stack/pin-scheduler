Privacy Policy

Last updated: October 11, 2026

Bikramdhatwalia Pin Scheduler is a personal tool used only by its owner to publish Pins to the owner's own Pinterest boards through the Pinterest API.

Data we access

The app uses the owner's Pinterest access token to read the owner's own boards and create Pins on them. It does not access other Pinterest users' data.

Data we store

No personal data of any user is collected, sold or shared. The access token is stored only as an encrypted secret in the owner's GitHub repository settings.

Third parties

Pins may link to products on Amazon. Amazon's own privacy policy applies when you visit those links. As an Amazon Associate the owner earns from qualifying purchases.

Contact

Questions can be raised through the GitHub repository: github.com/bikramdhatwaliaofficial-stack/pin-scheduler.
